## Create a session

1. Open **Open Play** and select **Create Open Play**.
2. Enter a session name, date, start and end time.
3. Set the maximum players, price per player and skill level.
4. Select the courts to reserve.
5. Choose a one-time, daily or weekly schedule. Set the number of sessions when repeating.
6. Select **Publish Open Play**.

## Check your schedule

The selected courts must be available during each session. Review the sessions shown in Open Play and in the calendar.
