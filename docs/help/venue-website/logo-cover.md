## Prepare images

Use clear images you have permission to use. The logo file limit is 1 MB and the cover limit is 2 MB. Follow the file type guidance in the form.

## Upload and save

Open **Booking setup**, select the logo or cover file in the branding section, then select **Save branding**. To remove an image, use its remove checkbox and save.

## Check the result

Open your venue site and signed-in workspace to confirm the correct branding.
