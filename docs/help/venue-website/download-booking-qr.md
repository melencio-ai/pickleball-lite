## Find the QR code

Open **Booking setup > Share your venue** and locate the booking QR code and download option.

## Use the code

Download the image and add it to signage, printed materials or social posts. Leave enough space around the code for scanning.

## Verify before printing

Scan it from another phone and check that it opens your own venue booking page. This QR opens a website; it is not the merchant payment QR.
