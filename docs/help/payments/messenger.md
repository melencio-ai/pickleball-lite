## Get your page link

Use your venue's official Messenger page identifier. Both https://m.me/yourpage and https://www.facebook.com/messages/t/yourpage are supported formats.

## Save the links

Open **Booking setup**. Set the general Messenger link under branding for customer enquiries. Set the payment verification Messenger link under **QR payments** for receipts.

## Test on both devices

Click the contact button from the public venue page and the receipt link from a test booking. Mobile uses m.me when a supported Messenger URL is configured; desktop uses the Facebook messages link. Check that both open your venue's correct account.
