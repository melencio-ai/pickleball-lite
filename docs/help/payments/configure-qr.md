## Before you start

Ask your payment provider for a merchant EMV QR code that supports generating a valid amount-prefilled QR. Use an authorized Philippine peso merchant account. Do not assume a personal QR or unsupported one-time transaction code will work.

## Configure payments

1. Open **Booking setup > QR payments**.
2. Paste the base merchant EMV code supplied by your provider.
3. Enter your payment verification Messenger link.
4. Confirm that your provider supports amount-prefilled codes.
5. Enable **Require QR payment for new bookings** and save.

## Test it

Use a test booking and scan the generated code in your payment app. Confirm the intended merchant and exact amount before sending money. If the code fails validation, contact your payment provider or Pickle Lite support.
