## Add a rate

1. Open **Booking setup > Time-based rates**.
2. Choose which courts and days the rate applies to.
3. Enter the start time, end time and hourly rate.
4. Select **Add rate**.

## Example

You can set a weekday evening rate for 18:00 to 22:00 while keeping the normal hourly rate for other times.

## Review your rates

Avoid conflicting or overlapping rate rules. Test bookings that start inside and outside the time window, and check the total before accepting payments.
