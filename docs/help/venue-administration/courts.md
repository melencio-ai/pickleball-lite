## Manage courts

1. Open **Venue settings > Courts**.
2. Enter a court name, hourly rate and optional indoor/outdoor type.
3. Save the new court.
4. To update a court, edit its existing row and save.

## Change availability

Use the court status control to make a court inactive when appropriate. For temporary maintenance, use a calendar block instead. Review existing reservations before making changes.

## Check your booking page

Verify that active courts and rates appear as expected.
