## Block time

1. Open **Calendar** and select **New** or an available slot.
2. Choose **Block court time**.
3. Select the court, date, start and end time.
4. Enter a reason and select **Save block**.

## Remove a block

Open the blocked entry, choose **Remove block**, and confirm removal.

## Close an entire date

For holidays or one-off closures, use **Booking setup > Holiday and one-off closures**. Review existing reservations separately before closing a date.
