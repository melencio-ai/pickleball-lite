## Check the venue

Sign in and choose the correct venue. Make sure onboarding is complete and the venue is published and active.

## Check access

Open **Subscription** to confirm that the venue has active booking access. An inactive subscription can prevent new bookings while existing records remain available.

## Test the correct link

Copy the current booking link from **Booking setup**. Try a private browser window. If it still fails, contact support with the venue name and public URL.
